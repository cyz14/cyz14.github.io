流形上仿射联络、Hessian、Laplacian的定义

by 《微分几何讲义》，DeepSeek，GPT

1仿射联络

1.1仿射联络的定义

设\(M\)是光滑流形，\(T M\)是切丛，\(\Gamma (T M)\)表示光滑向量场空间。

一个仿射联络是一个映射

\(\displaystyle \nabla : \Gamma (T M) \times \Gamma (T M) \rightarrow \Gamma (T M), \quad (X, Y) \mapsto \nabla_X Y\)

满足两条公理：

(A1) 对第一个变量\(C^{\infty} (M)\)-线性

\(\displaystyle \nabla_{f X + g Y} Z = f \nabla_X Z + g \nabla_Y Z.\)

(A2) 对第二个变量满足 Leibniz 律

\(\displaystyle \nabla_X (f Y) = X (f) Y + f \nabla_X Y.\)

这条说明：\(\nabla_X\)作用在向量场上像一个“沿\(X\)方向的导数”。

1.2Leibniz律：从向量场扩展到张量场

Leibniz律不只是对 \(f Y\) 这一条。它是把\(\nabla\)从向量场唯一扩展到所有张量场的核心原则。

1.2.1对函数

规定

\(\displaystyle \nabla_X f = X (f) .\)

1.2.2对\(1\)-形式

要求\(\nabla\)与缩并相容，即对\(1\)-形式\(\omega\)和向量场\(Y\)，

\(\displaystyle \nabla_X (\omega (Y)) = (\nabla_X \omega) (Y) + \omega (\nabla_X Y) .\)

左边是函数的方向导数\(X (\omega (Y))\)。移项得

\(\displaystyle (\nabla_X \omega) (Y) = X (\omega (Y)) - \omega (\nabla_X Y) .\)

这里的负号是Leibniz律的产物。

1.2.3对张量积

要求

\(\displaystyle \nabla_X (T \otimes S) = (\nabla_X T) \otimes S + T \otimes (\nabla_X S) .\)

1.2.4对一般\((r, s)\)型张量

综合以上，对\(T \in \Gamma (T^{r, s} M)\)，

\(\displaystyle (\nabla_X T) (\omega^1, \ldots, \omega^r, Y_1, \ldots, Y_s) = X (T (\omega^1, \ldots, Y_s)) - \sum_a T (\ldots, \nabla_X \omega^a, \ldots, Y_s) - \sum_b T (\ldots, \omega^a, \ldots, \nabla_X Y_b, \ldots) .\)

协变指标 \((Y_b)\)带负号，逆变指标 \((\omega^a)\) 也带负号，因为缩并时要扣掉“标架变化”的部分。

前面Hessian的协变导数

\(\displaystyle (\nabla_X H) (Y, Z) = X (H (Y, Z)) - H (\nabla_X Y, Z) - H (Y, \nabla_X Z)\)

正是这个公式在\((0, 2)\)型张量上的特例。

1.3度量相容性

设\((M, g)\)是黎曼流形，\(\nabla\)是仿射联络。称\(\nabla\)与度量相容，若

\(\displaystyle \nabla g = 0,\)

等价地，对任意向量场 \(X, Y, Z\)，

\(\displaystyle X (g (Y, Z)) = g (\nabla_X Y, Z) + g (Y, \nabla_X Z) .\)

直观意义

  • 沿任意曲线平行移动向量时，内积保持不变；

  • 平行移动是正交变换；

  • 可以用\(\nabla\)和\(g\)自由地降指标、升指标，因为\(g\)是平行的。

局部坐标形式

\(\displaystyle \partial_k g_{i j} = \Gamma_{k i}^l g_{l j} + \Gamma^l_{k j} g_{i l} .\)

1.4无挠性

仿射联络的挠率张量定义为

\(\displaystyle T (X, Y) = \nabla_X Y - \nabla_Y X - [X, Y] .\)

称\(\nabla\)无挠，若

\(\displaystyle \nabla_X Y - \nabla_Y X = [X, Y] .\)

局部坐标中，无挠等价于Christoffel符号对称：

\(\displaystyle \Gamma_{i j}^k = \Gamma_{j i}^k .\)

1.5Levi-Civita 联络：基本定理

黎曼几何基本定理：在黎曼流形\((M, g)\)上，存在唯一的仿射联络\(\nabla\)，同时满足:

  1. 无挠：\(\nabla_X Y - \nabla_Y X = [X, Y]\);

  2. 度量相容：\(\nabla g = 0\).

这个联络称为Levi-Civita联络（或黎曼联络）。

Koszul公式

它由度量唯一确定：

\(\displaystyle 2 g (\nabla_X Y, Z) = X (g (Y, Z)) + Y (g (X, Z)) - Z (g (X, Y)) + g ([X, Y], Z) - g ([X, Z], Y) - g\)

局部坐标：Christoffel符号

\(\displaystyle \nabla_{\partial_i} \partial_j = \Gamma_{i j}^k \partial k\)
\(\displaystyle \Gamma_{i j}^k = \frac{1}{2} g^{k l} (\partial_i g_{j l} + \partial_j g_{i l} - \partial_l g_{i j}) .\)

1.6应用

1.6.1Hessian的对称性来自无挠

\(\displaystyle (\operatorname{Hess}f) (X, Y) = (\nabla_X d f) (Y) = X (Y f) - (\nabla_X Y) f.\)

交换\(X, Y\)相减：

\(\displaystyle (\operatorname{Hess}f) (X, Y) - (\operatorname{Hess}f) (Y, X) = [X, Y] f - (\nabla_X Y - \nabla_Y X) f.\)

无挠时\(\nabla_X Y - \nabla_Y X = [X, Y]\)，右边为0。所以

\(\displaystyle \operatorname{Hess}f (X, Y) =\operatorname{Hess}f (Y, X) .\)

1.6.2Hessian写成内积形式依赖度量相容

\(\displaystyle \operatorname{Hess}f (X, Y) = g (\nabla_X \nabla f, Y)\)

中，\(\nabla f\) 由 \(g (\nabla f, X) = d f (X)\)定义，内积是\(g\)。度量相容保证这套“升指标-求导-降指标”的操作与 \(\nabla d f\) 一致。

1.6.3联络Laplacian的伴随依赖度量

\(\displaystyle L = - \nabla^{\ast} \nabla\)

中 \(\nabla^{\ast}\) 是 \(\nabla\) 关于 \(L^2\) 内积的正式伴随。\(L^2\) 内积由 \(g\) 和体积元定义，所以 \(L\) 的良定义依赖度量相容性。

1.6.4正交标架和迹

\(\displaystyle \langle L \nabla f, e_j \rangle = \sum_i (\nabla_{e_i} H) (e_j, e_i)\)

中，\(\{ e_i \}\)是 \(g\)-正交标架，\(\sum_i\)是取迹。这些都依赖 \(g\) 和 \(\nabla g = 0\)。

2Hessian

2.1预备记号

切丛 \(T M\)，余切丛 \(T^{\ast} M\)。

向量场空间 \(\Gamma (T M)\)，1-形式空间 \(\Gamma (T^{\ast} M)\)。

度量 \(g (\cdot, \cdot) = \langle \cdot, \cdot \rangle\)。

梯度 \(\nabla f =\operatorname{grad}f\) 由

\(\displaystyle g (\nabla f, X) = d f (X) = X f\)

唯一确定。

协变导数 \(\nabla_X Y\) 对 \(X\) 是 \(C^{\infty} (M)\)-线性的，对 \(Y\) 满足Leibniz律。

2.2Hessian的定义

定义 1. (协变导数定义)

函数\(f \in C^{\infty} (M)\)的Hessian定义为 \(d f\) 的协变导数

\(\displaystyle \operatorname{Hess}f := \nabla d f \in \Gamma (T^{\ast} M \otimes T^{\ast} M) .\)

它对 \(X, Y \in \Gamma (T M)\)的作用为

\(\displaystyle (\operatorname{Hess}f) (X, Y) = (\nabla_X d f) (Y) = X (Y f) - (\nabla_X Y) f.\)

定义 2. （梯度-内积定义）

等价地，

\(\displaystyle (\operatorname{Hess}f) (X, Y) = g (\nabla_X \nabla f, Y) .\)

这与定义1一致，因为

\(\displaystyle g (\nabla_X \nabla f, Y) = X g (\nabla f, Y) - g (\nabla f, \nabla_X Y) = X (Y f) - (\nabla_X Y) f.\)

性质

  1. 对称性（由\(\nabla\)无挠）

    \(\displaystyle (\operatorname{Hess}f) (X, Y) = (\operatorname{Hess}f) (Y, X) .\)

  2. 张量性：\(\operatorname{Hess}f\) 是 \((0, 2)\)型张量，对 \(X, Y\) 均 \(C^{\infty} (M)\)-线性。

  3. 局部坐标：

    \(\displaystyle (\operatorname{Hess}f)_{i j} = \partial_i \partial_j f - \Gamma_{i j}^k \partial_k f.\)

    在临界点 \(d f = 0\) 处退化为普通二阶偏导矩阵。

  4. 与度量的关系：\(\operatorname{Hess}f\) 与 \(g\) 同型，可定义其 \(g\)-迹，即Laplace算子。

2.3\(\nabla H\): Hessian 的协变导数

令

\(\displaystyle H =\operatorname{Hess}f = \nabla d f.\)

它是一个 \((0, 2)\)-型张量。对它再求协变导数，得到 \((0, 3)\)-型张量

\(\displaystyle \nabla H \in \Gamma (T^{\ast} M \otimes T^{\ast} M \otimes T^{\ast} M) .\)

定义. (Leibniz 扩展)

对 \(X, Y, Z \in \Gamma (T M)\),

\(\displaystyle (\nabla_X H) (Y, Z) = X (H (Y, Z)) - H (\nabla_X Y, Z) - H (Y, \nabla_X Z) .\)

取 \(X = e_i\):

\(\displaystyle (\nabla_{e_i} H) (Y, Z) = e_i (H (Y, Z)) - H (\nabla_{e_i} Y, Z) - H (Y, \nabla_{e_i} Z) .\)

局部坐标

\(\displaystyle (\nabla_i H)_{j k} = \partial_i H_{j k} - \Gamma_{i j}^l H_{l k} - \Gamma_{i k}^l H_{j l} .\)

性质

  1. 张量性：\(\nabla H\)对 \(X, Y, Z\) 均 \(C^{\infty} (M)\)-线性

  2. 对称性：由于 \(H\) 对称且 \(\nabla\)无挠，\(\nabla H\) 在后两个指标上对称：

    \(\displaystyle (\nabla_X H) (Y, Z) = (\nabla_X H) (Z, Y) .\)

  3. \(\nabla H\) 是 \(\operatorname{Hess}f\) 的三阶导数，在临界点附近刻画 Hessian 的变化率。

2.4Laplace 算子的定义

流形上有两个常用Laplace算子

2.4.1Laplace-Beltrami 算子，作用在函数上

定义. (散度-梯度）

\(\displaystyle \Delta f =\operatorname{div} (\nabla f) .\)

其中散度由

\(\displaystyle \operatorname{div}X =\operatorname{tr}_g (\nabla X) = \sum_i g (\nabla_{e_i} X, e_i)\)

定义。

定义. (Hessian 的迹)

等价地

\(\displaystyle \Delta f =\operatorname{tr}_g (\operatorname{Hess}f) = \sum_i (\operatorname{Hess}f) (e_i, e_i) = \sum_i g (\nabla_{e_i} \nabla f, e_i) .\)

局部坐标

\(\displaystyle \Delta f = \frac{1}{\sqrt{| g |}} \partial_i \left( \sqrt{| g |} g^{i j} \partial_j f \right) .\)

性质

  • \(\Delta f\) 是标量函数。

  • 符号约定：几何中常用 \(\Delta =\operatorname{div} \nabla\)(非负谱的反号取决于约定)，分析中常用\(- \Delta\)使其正定。

  • 在 \(\mathbb{R}^n\) 中退化为普通 Laplacian \(\sum_i \partial_i^2 f\).

2.4.2联络Laplacian （Bochner Laplacian，作用在张量场/向量场上）

对向量场 \(X\),

\(\displaystyle L X = - \nabla^{\ast} \nabla X = \sum_i \left( \nabla_{e_i} \nabla_{e_i} X - \nabla_{\nabla_{e_i} e_i} X \right) .\)

符号约定不同则整体差负号。

对1-形式 \(\omega\),同理

\(\displaystyle L \omega = - \nabla^{\ast} \nabla \omega,\)

局部上

\(\displaystyle (L \omega)_j = - g^{i k} (\nabla_i \nabla_k \omega)_j .\)

与函数Laplacian的关系

对函数 \(f\)，

\(\displaystyle L f {=\!\!=} - \nabla^{\ast} \nabla f = - \Delta f\)

（在 \(\Delta =\operatorname{div} \nabla\)约定下差负号）。

但对1-形式\(d f\)，\(L (d f)\)与 \(d (\Delta f)\) 一般不同，二者由 Weitzenbock 公式联系

\(\displaystyle \Delta_H d f = d (\Delta f) +\operatorname{Ric} (\nabla f),\)

其中 \(\Delta_H\) 是 Hodge-de Rham Laplacian。联络 Laplacian \(L\) 与 Hodge Laplacian也差 Ricci项。

2.5\(\langle L \nabla f, e_j \rangle\)与 \(\nabla H\)的关系

这是前面讨论的核心恒等式。取 \(X = \nabla f\), \(H =\operatorname{Hess}f\).

由联络 Laplacian定义

\(\displaystyle \langle L \nabla f, e_j \rangle = \sum_i \left[ \langle \nabla_{e_i} \nabla_{e_i} \nabla f, e_j \rangle - \left\langle \nabla_{\nabla_{e_i} e_i} \nabla f, e_j \right\rangle \right] .\)

利用

\(\displaystyle \langle \nabla_{e_i} \nabla f, e_j \rangle = H (e_i, e_j)\)

并展开

\(\displaystyle e_i (H (e_i, e_j)) = \langle \nabla_{e_i} \nabla_{e_i} \nabla f, e_j \rangle + \langle \nabla_{e_i} \nabla f, \nabla_{e_i} e_j \rangle,\)

得到

\(\displaystyle \langle \nabla_{e_i} \nabla_{e_i} \nabla f, e_j \rangle = e_i H (e_i, e_j) - H (e_i, \nabla_{e_i} e_j) .\)

代回：

\(\displaystyle \langle L \nabla f, e_j \rangle = \sum_i [e_i H (e_i, e_j) - H (e_i, \nabla_{e_i} e_j) - H (\nabla_{e_i} e_i, e_j)] .\)

方括号正是 \((\nabla_{e_i} H) (e_i, e_j)\)，于是

\(\displaystyle \langle L \nabla f, e_j \rangle = \sum_i (\nabla_{e_i} H) (e_i, e_j) .\)

再由 \(H\) 对称，

\(\displaystyle \langle L \nabla f, e_j \rangle = \sum_i (\nabla_{e_i} H) (e_j, e_i) .\)

3Bochner公式

为什么要计算梯度平方的Laplacian？因为我们想把“函数变化得有多快”变成一个能用最大值原理控制的标量问题。Bochner公式把这个标量的Laplacian分解成 Hessian 的非负平方项、原方程提供的项以及曲率项。

以下设 \((M^n, g)\) 是光滑黎曼流形，\(f \in C^{\infty} (M)\)，\(\nabla\) 是 Levi-Civita 联络。统一采用 \(\Delta =\operatorname{div}\operatorname{grad}\)，并取 \(R (X, Y) Z = \nabla_X \nabla_Y Z - \nabla_Y \nabla_X Z - \nabla_{[X, Y]} Z\)，使单位球面的截面曲率为正。

定义. Bochner恒等式

\(\displaystyle \frac{1}{2} \Delta | \nabla f |^2 = | \operatorname{Hess}f |^2 + \langle \nabla f, \nabla \Delta f \rangle +\operatorname{Ric} (\nabla f, \nabla f)\)

欧氏空间情形

记 \(f_j = \partial_j f\)，\(f_{i j} = \partial_i \partial_j f\)。对平方连续求两次导数

\(\displaystyle \begin{array}{rl} \frac{1}{2} \Delta | \nabla f |^2 & = \frac{1}{2} \sum_i \partial_i^2 \left( \sum_j f_j^2 \right)\\ & = \sum_{i, j} f_{i j}^2 + \sum_j f_j \sum_i \partial_i^2 \partial_j f\\ & = | D^2 f |^2 + \langle \nabla f, \nabla \Delta f \rangle . \end{array}\)

在流形上，先对向量场的长度平方求导

令\(V = \nabla f\)。为区分标量Laplacian与向量场上的算子，记

\(\displaystyle L V := \sum_i \left( \nabla_{e_i} \nabla_{e_i} V - \nabla_{\nabla_{e_i} e_i} V \right) .\)

这里 \(\{ e_i \}\) 是局部正交单位标架，\(L\) 是二阶协变导数的迹。固定一点\(p\)，选取满足 \(\nabla_{e_i} e_j (p) = 0\) 的标架。利用联络和度量相容，在 \(p\) 有

\(\displaystyle \begin{array}{rl} \frac{1}{2} \Delta | V |^2 & = \sum_i e_i \langle \nabla_{e_i} V, V \rangle\\ & = \sum_i | \nabla_{e_i} V |^2 + \left\langle \sum_i \nabla_{e_i} \nabla_{e_i} V, V \right\rangle\\ & = | \nabla V |^2 + \langle L V, V \rangle \end{array}\)

当 \(V = \nabla f\) 时，\(| \nabla V |^2 = | \operatorname{Hess}f |^2\)。因此，剩下的问题只有一个：\(L \nabla f\) 与 \(\nabla \Delta f\) 相差什么？

交换导数产生Ricci曲率

\(\displaystyle L \nabla f = \nabla \Delta f +\operatorname{Ric} (\nabla f, \cdot)^{\sharp}\)

\(\sharp\) 表示用度量把一形式变成向量。将这个恒等式代入上面的平方求导公式，就得到Bochner公式。下面展开它的证明。

证明.

令 \(H =\operatorname{Hess}f = \nabla d f\). 仍使用上面的标架。由Hessian的对称性

\(\displaystyle \langle L \nabla f, e_j \rangle = \sum_i (\nabla_{e_i} H) (e_i, e_j) = \sum_i (\nabla_{e_i} H) (e_j, e_i)\)

对一形式 \(\alpha\)，协变导数的变换公式是

\(\displaystyle ((\nabla_X \nabla_Y - \nabla_Y \nabla_X - \nabla_{[X, Y]}) \alpha) (Z) = - \alpha (R (X, Y) Z) .\)

取 \(\alpha = d f\)，并利用联络无挠，得到

\(\displaystyle (\nabla_{e_i} H) (e_j, e_i) - (\nabla_{e_i} H) (e_i, e_i) = - \langle \nabla f, R (e_i, e_j) e_i \rangle .\)

于是

\(\displaystyle \begin{array}{rl} \langle L \nabla f, e_j \rangle & = \sum_i (\nabla_{e_j} H) (e_i, e_i) - \sum_i \langle \nabla f, R (e_i, e_j) e_i \rangle\\ & = e_j (\Delta f) +\operatorname{Ric} (e_j, \nabla f) . \end{array}\)

第一项是 Hessian 的迹的导数。第二项用到曲率算子关于度量的反对称性与 Ricci 曲率的定义:

\(\displaystyle - \sum_i \langle \nabla f, R (e_i, e_j) e_i \rangle = \sum_i \langle R (e_i, e_j) \nabla f, e_i \rangle =\operatorname{Ric} (e_j, \nabla f) .\)

这对每个 \(e_j\) 都成立，所以给出了所需的向量恒等式。\(\Box\)

3.1为什么选择梯度平方的Laplacian

假设 \(u\) 满足一个方程，如 \(\Delta u = 0\)，目标是估计它的变化率 \(| \nabla u |\)。这个选择有三个具体原因：

  • 取梯度：直接对应我们想控制的变化率

  • 取平方范数：把向量换成标量，且 \(| \nabla u |^2\)在临界点光滑；\(| \nabla u |\)未必如此。平方求导还产生有利的Hessian平方项。

  • 取 Laplacian：能连接原方程，并且在标量函数的内部局部最大点有 \(\Delta w \leq 0\)，可以使用最大值原理。

例如，若 \(u\) 调和且 \(\operatorname{Ric} \geq 0\)，则

\(\displaystyle \frac{1}{2} \Delta | \nabla u |^2 = | \operatorname{Hess}u |^2 +\operatorname{Ric} (\nabla u, \nabla u) \geq 0.\)

梯度平方因此是次调和函数：几何条件已变成标量微分不等式。

但仅凭这一点，不能在任意非紧流形上直接得到梯度上界，因为它未必取得最大值，也缺少能限制其大小的项。

3.2用于梯度估计：正的二次项怎么出现

设\(u\)在所讨论的开集上光滑、严格为正且调和，即 \(u > 0, \Delta u = 0\)。令 \(f = \log u, w = | \nabla f |^2\)。取对数是为了控制相对变化率: \(u \mapsto c u (c > 0)\)只使\(f\)增加常数，不改变它的梯度。下面逐步计算 \(\Delta f\)。

取 \(a = u^{- 1}, V = \nabla u\)。注意 \(\nabla (u^{- 1}) = - u^{- 2} \nabla u\)。于是

\(\displaystyle \begin{array}{rl} \Delta f & =\operatorname{div} (\nabla f) =\operatorname{div} (u^{- 1} \nabla u)\\ & = \langle \nabla (u^{- 1}), \nabla u \rangle + u^{- 1} \operatorname{div} (\nabla u)\\ & = - u^{- 2} \langle \nabla u, \nabla u \rangle + u^{- 1} \Delta u\\ & = \frac{\Delta u}{u} - \frac{| \nabla u |^2}{u^2} = - \frac{| \nabla u |^2}{u^2}\\ & = - w \end{array}\)

因此，

\(\displaystyle \Delta f = - | \nabla f |^2 = - w\)

所以 \(u\) 调和并不意味着 \(\log u\) 调和；对数产生的梯度平方项恰好把线性方程 \(\Delta u = 0\) 变成后续估计所需的非线性方程。负号来自 \((\log s)'' = - s^{- 2}\)，不是来自曲率。

最后，为看清它怎样代入 Bochner 公式，对 \(\Delta f = - w\) 再取梯度：

\(\displaystyle \nabla \Delta f = - \nabla w, \quad \langle \nabla f, \nabla \Delta f \rangle = - \langle \nabla f, \nabla w \rangle .\)

对 \(f\) 使用 Bochner 公式，便有

\(\displaystyle \frac{1}{2} \Delta w = | \operatorname{Hess}f |^2 - \langle \nabla f, \nabla w \rangle +\operatorname{Ric} (\nabla f, \nabla f) .\)

在一点把对称的 Hessian 对角化，设其特征值为 \(\lambda_1, \ldots, \lambda_n\)。Cauchy-Schwarz 不等式给出

\(\displaystyle (\Delta f)^2 = \left( \sum_i \lambda_i \right)^2 \leq n \sum_i \lambda_i^2 = n | \operatorname{Hess}f |^2 .\)

又因 \(\Delta f = - w\)，得到 \(| \operatorname{Hess}f |^2 \geq w^2 / n\).

若 \(\operatorname{Ric} \geq - (n - 1) K g\)，其中 \(K \geq 0\)，则

定义. 梯度估计的核心微分不等式

\(\displaystyle \frac{1}{2} \Delta w \geq \frac{w^2}{n} - (n - 1) K w - \langle \nabla f, \nabla w \rangle .\)

正项 \(w^2 / n\) 是限制梯度不能太大的关键。假如 \(w\) 在内部取得局部最大值，那么该点 \(\nabla w = 0, \Delta w \leq 0\)，从而

\(\displaystyle 0 \geq \frac{w^2}{n} - (n - 1) K w, \quad w \leq n (n - 1) K.\)

这是最大点处的条件性结论，不是对任意局部调和函数已经完成的估计。实际证明要在球内对截断后的\(\psi w\) 使用最大值原理，控制截断产生的误差，最终得到 \(| \nabla \log u | \leq C_n \left( \sqrt{K} + 1 / R \right)\)的内部估计。

用于距离比较：梯度长度已知时反过来用

设流形完备、连通、无边界且 \(n \geq 2\)，取 \(r = d (p, \cdot)\)。只在 \(M\backslash (\{ p \} \cup \operatorname{Cut} (p))\) 上作下面的点态计算。由于 \(| \nabla r |^2 = 1\)，Bochner公式左边为零：

\(\displaystyle 0 = | \operatorname{Hess}r |^2 + \partial_r (\Delta r) +\operatorname{Ric} (\partial_r, \partial_r), \quad \partial_r = \nabla r.\)

由 \(\operatorname{Hess}r (\partial_r, \cdot) = 0\)，Hessian的迹只在 \(n - 1\) 个横向方向上求和，因此

\(\displaystyle | \operatorname{Hess}r |^2 \geq \frac{(\Delta r)^2}{n - 1} .\)

若 \(\operatorname{Ric} \geq (n - 1) \kappa g\)，沿从 \(p\) 出发、初始方向是 \(v\) 的径向测地线 \(\gamma_v (t)\), 令 \(m (t) = \Delta r (\gamma_v (t))\)。在到达割迹之前 (即 \(0 < t < c (v)\)，其中 \(c (v)\) 是该方向的割时间)，距离函数 \(r\) 光滑，因此得到

\(\displaystyle m' + \frac{m^2}{n - 1} + (n - 1) \kappa \leq 0.\)

这正是Laplacian比较所需的Riccati型不等式。对距离函数，梯度长度已知，用 Bochner 公式控制 \(\Delta r\)；对正调和函数，方程已知，用它控制 \(| \nabla \log u |\)。完整矩阵 Riccati 方程还需 Jacobi 场，不能仅由这条取迹的恒等式恢复。
